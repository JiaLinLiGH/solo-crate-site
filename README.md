# solo-crate-site

Marketing site for **Solo Crate** — a 100% offline Mac receipt manager for
self-employed people, freelancers, and 1099 contractors. Companion to the
macOS app `com.solocrate.app`.

## Stack

- [Next.js 14](https://nextjs.org/) (App Router) with [React 18](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/) (strict)
- [Tailwind CSS 3](https://tailwindcss.org/) with a custom palette (`ink`, `moss`, `amber`)
- Static export (`output: 'export'`) for GitHub Pages
- Local-first copy (no analytics, no third-party trackers)

## Pages

- `/` — full marketing landing page composed of:
  - Hero with mock three-pane app window
  - Features grid
  - 4-step workflow
  - Schedule C showcase (with live IRS line totals)
  - Rules engine demo (Boolean tree)
  - Privacy / data-flow section
  - CPA-ready export preview
  - Comparison table vs Expensify / Smart Receipts / 1tap Receipts
  - FAQ accordion
  - Final CTA
- `/pricing` — tier comparison + pricing-specific FAQ
- `/faq` — full FAQ page
- `/changelog` — version history
- `/privacy` + `/terms` — legal pages
- `/sitemap.xml` + `/robots.txt` auto-generated by Next

## Local development

```bash
npm install
npm run dev           # http://localhost:3000/solo-crate-site/
npm run typecheck
npm run build         # writes static site to ./out
```

## Deployment

Auto-deploys to GitHub Pages via `.github/workflows/deploy.yml` on every
push to `main`.

**Live site: [jialinligh.github.io/solo-crate-site](https://jialinligh.github.io/solo-crate-site/)**

See [DEPLOYMENT.md](./DEPLOYMENT.md) for full setup and custom-domain instructions.

## Project structure

```
.
├── app/                  # Next.js App Router pages
│   ├── page.tsx          # Home
│   ├── pricing/          # /pricing
│   ├── faq/              # /faq
│   ├── changelog/        # /changelog
│   ├── privacy/          # /privacy
│   └── terms/            # /terms
├── components/           # React Server Components (no client JS for static content)
├── lib/content.ts        # All marketing copy lives here
├── public/               # Static assets (icons + opengraph-image.png)
├── scripts/              # Asset build helpers (build-favicon.mjs)
├── .github/workflows/    # GitHub Actions
├── next.config.mjs       # output: 'export' + basePath: '/solo-crate-site'
└── tailwind.config.ts
```
